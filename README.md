# Kirby Nightmare in Dream Land Tracker for Archipelago

## Features

* Ability Tracking
* Star Rod Piece Tracking
* Arena and Museum Door Keys Tracking
* Advanced Logic Setting
* Show Abilities on Levels Settings
  * Level abilities can be hidden or only shown when an ability is unlocked (default)

## Installation

Download the latest release from the releases section, and then move it into `/poptracker/packs/` and you're all set!

PopTracker v0.35.4 or higher is recommended.
